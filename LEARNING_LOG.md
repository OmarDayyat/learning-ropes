# Learning log

## Skills checklist

Tick a skill when you can do it on your own, without hints.

- [ ] Create a branch, commit and push, then open a PR that closes an Issue
- [ ] Review someone else's PR and leave useful comments
- [ ] Respond to review feedback with follow-up commits
- [ ] Resolve a merge conflict without help
- [ ] Rebase a branch and squash its commits into a clean history
- [ ] Fix a failing CI check before merging
- [ ] Undo a bad change with `revert`, and find a bug's commit with `bisect`
- [ ] Tag `v1.0.0` and publish a GitHub release with notes
